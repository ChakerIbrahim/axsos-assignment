# ☕ Cafe Java

A Java console application that simulates a café ordering system. Built as part of the **Java Stack** course on Axsos Academy.

---

## 📋 About the Project

Cafe Java is a beginner Java assignment that demonstrates the use of core Java fundamentals including variables, data types, string concatenation, boolean logic, and if-statements — all applied in a real-world café simulation context.

---

## 🚀 Features

- Greets customers by name using string concatenation
- Tracks menu item prices using `double` variables
- Manages order status using `boolean` flags
- Prints pending or ready messages based on order status
- Calculates order totals including multi-item orders
- Handles billing corrections when a wrong item was charged

---

## 🧠 Concepts Used

| Concept | Usage |
|---|---|
| `String` variables | Customer names, greeting messages |
| `double` variables | Menu item prices |
| `boolean` variables | Order ready/pending status |
| String concatenation | Building output messages |
| `if / else` statements | Checking order status |
| Arithmetic operators | Calculating totals and differences |
| `!` (NOT operator) | Flipping boolean order status |

## 💻 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/cafe-java.git
   ```

2. Open the project in **Eclipse IDE**

3. Navigate to `CafeJava.java`

4. Right-click the file → **Run As** → **Java Application**

5. View the output in the **Console** tab
